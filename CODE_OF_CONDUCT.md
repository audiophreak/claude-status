# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good intent, welcome people of every
background and experience level, and keep discussion focused on the work. Harassment,
personal attacks, discriminatory language and publishing others' private information are not
acceptable in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through a
[private security advisory](https://github.com/audiophreak/claude-status/security/advisories/new)
(mark the title "Conduct report") or by contacting the maintainer via their GitHub profile.
Reports are handled confidentially. The maintainer may remove content, or warn, suspend or
block participants, as described in the Contributor Covenant's enforcement guidelines.
